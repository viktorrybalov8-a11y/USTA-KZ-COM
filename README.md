# USTA.KZ Mobile

Восстановленная Flutter-кодовая база мобильного приложения строительного маркетплейса Казахстана.

## Реализовано в текущей демонстрационной версии

- Лента заказов с поиском и фильтром по категориям.
- Форма создания заказа с проверкой телефона, города и описания.
- Сохранение и удаление заказов на текущем устройстве.
- Просмотр деталей заказа.

## Текущие ограничения

Это локальная демонстрационная сборка. Заказы не публикуются в общей базе и не доступны другим пользователям. В исходном архиве отсутствуют настройки Firebase, Android-папка проекта и release-подпись. Для запуска нужны Flutter SDK и генерация платформенных файлов через `flutter create .`.

## Следующий этап перед выпуском

1. Подключить Firebase проект `usta-kz` с Auth, Firestore и Storage.
2. Добавить регистрацию/вход, профили, загрузку фото и права владельца заказа.
3. Добавить общий чат, push-уведомления, рекламу, USTA Business и админ-панель.
4. Сгенерировать Android-проект, настроить подпись релиза, выполнить `flutter analyze`, тесты и сборку AAB.

## GitHub и Android APK

Репозиторий: https://github.com/viktorrybalov8-a11y/USTA-KZ-COM

Workflow Flutter checks and Android APK генерирует Android-проект, проверяет код, запускает тесты и собирает тестовый APK. После успешного выполнения архив USTA-KZ-debug-apk доступен во вкладке Actions. Это тестовая сборка локальной версии, не релиз для Google Play.
